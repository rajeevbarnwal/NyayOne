## Conventions

Every table except `audit_events` derives from `TimestampedBase` and therefore carries a common column set:

| Column | Type | Null | Key/Index | Notes |
|---|---|---|---|---|
| `id` | UUID | NOT NULL | PK (`pk_<table>`) | Application-generated `uuid4` (`Uuid(as_uuid=True)`). |
| `created_at` | timestamptz | NOT NULL | | Server default `now()`. |
| `updated_at` | timestamptz | NOT NULL | | Server default `now()`; ORM `onupdate` bumps on write. |
| `deleted_at` | timestamptz | NULL | | Soft-delete marker; `NULL` = live row. |
| `metadata_json` | JSON | NULL | | Free-form audit-friendly payload. |

Additional physical conventions:

- **UUID PKs** on every table; portable `Uuid(as_uuid=True)` mapping (Postgres `uuid`).
- **timestamptz** (`DateTime(timezone=True)`) for all temporal columns — UTC.
- All **foreign keys are indexed** and declared **`ON DELETE CASCADE`**.
- Index/constraint names follow the shared naming convention: `ix_%(column_0_label)s`, `uq_%(table)s_%(col)s`, `fk_%(table)s_%(col)s_%(referred)s`, `pk_%(table)s`.

### Sensitive-data handling (never plaintext)

Raw **mobile number, date of birth, and OTP are never stored in plaintext.** Sensitive identifiers use one or both of:

- **Keyed lookup hash** (`*_hash`, `String(64)`) — deterministic keyed hash for equality lookups / uniqueness (see `app.core.crypto`). Not reversible.
- **Fernet ciphertext** (`*_ct`, `String(512)`) — authenticated symmetric ciphertext for authorized display/decrypt.

| Field | Hash column | Ciphertext column | Plaintext stored? |
|---|---|---|---|
| Mobile | `student_registrations.mobile_hash` | `student_registrations.mobile_ct` | No |
| Date of birth | — | `student_registrations.dob_ct` | No |
| OTP | `otp_challenges.verifier_hash` (verifier only) | — | No |
| Enrolment no. | `student_profiles.enrolment_hash` | `student_profiles.enrolment_ct` | No |
| Institutional email | `student_profiles.institutional_email_hash` | `student_profiles.institutional_email_ct` | No |
| Bar enrolment | — | `student_profiles.bar_enrolment_ct` | No |
