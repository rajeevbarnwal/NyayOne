# Visual reference only

The files in this directory are appearance references. They are not executable product specifications.

Known visible and interactive contradictions are retained from the Claude prototype:

- The popup screenshot and HTML may display `67%` and `S-14`. The approved implementation uses server progress and hosts the popup on S-07.
- The HTML contains demo state, fixed timers, route aliases, and reviewer controls that must not enter application code.
- OTP, consent, profile, guardian, verification, persistence, and routing behavior in the HTML is non-authoritative.

All names, masked destinations, academic records, and profile values shown here are synthetic design fixtures. Plausible raw student and mentor identities in the source HTML were replaced with demo values, and the executable artifact uses the reserved `example.edu` domain.

Use `../ENGINEERING_CONTRACT.md`, `../SCREEN_MAP.md`, and `../ACCEPTANCE_MATRIX.md` for implementation.
